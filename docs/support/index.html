VibeColor 技术支持

版本 1.0.0 更新 2026年4月13日

欢迎使用 VibeColor。

如果您在安装、使用、订阅或保存作品时遇到问题，可以通过本页面提供的联系方式获得支持。本页面也可作为 VibeColor 在 App Store 的技术支持网址使用。

一、支持联系方式

1.1 支持邮箱

  • 邮箱：vibecolor@163.com
  • 电话：15910783273
  • 我们会尽量在 3 至 5 个工作日内回复

1.2 来信建议附带的信息

为了更快定位问题，建议您在邮件中尽量提供：

  • 设备型号与 iOS 版本
  • VibeColor App 版本号
  • 问题出现的具体步骤
  • 问题截图或录屏（如方便提供）
  • 如涉及购买问题，请说明订阅类型、购买时间与“恢复购买”结果

请勿在邮件中发送完整支付账号、银行卡号或其他敏感隐私信息。

二、可支持的问题范围

  • App 无法启动、闪退或界面显示异常
  • 导入照片、参考图加载、相册权限相关问题
  • 调色、裁剪、保存、导出或分享相关问题
  • 订阅购买、恢复购买、权益显示异常
  • 使用建议、体验反馈与功能建议

三、常见问题

3.1 无法访问照片

  • 请在 iPhone 的“设置 -> 隐私与安全性 -> 照片”中确认 VibeColor 已获得所需权限
  • 若系统权限为“部分照片”，App 仅能访问您已授权的内容

3.2 恢复购买后权益未更新

  • 请在稳定网络环境下再次点击“恢复购买”
  • 请确认当前设备登录的是完成购买时所使用的 Apple 账户
  • 若仍未恢复，请通过支持邮箱联系我们，并附上设备信息与购买说明

3.3 保存或导出失败

  • 请确认系统照片权限正常、设备存储空间充足
  • 若问题持续，请附上机型、系统版本与操作步骤发送给我们
