VibeColor 隐私政策

版本 1.0.0 更新 2026年3月31日

VibeColor（以下简称“本应用”或“我们”）非常重视您的隐私与个人信息安全。本应用在设计上遵循最小数据收集原则，仅在必要范围内处理信息，并尽可能在您的设备本地完成所有数据处理。

请您在使用本应用前仔细阅读本隐私政策，以了解我们如何处理您的信息。

一、我们收集的信息

1. 照片访问权限

为了实现图片导入与编辑功能，VibeColor需要访问您的照片库。

  • 我们会在使用前请求您的授权
  • 您可以随时在系统设置中关闭权限

重要说明：

您选择的照片仅用于本地处理，我们不会主动收集或上传您的照片。

2. 本地数据处理

VibeColor的核心图像处理功能（包括色彩映射、风格转换等）完全在设备本地执行：

  • 不会上传图片至服务器
  • 不会建立用户图片数据库
  • 不会对图片内容进行远程分析

这意味着我们无法访问或存储您的照片内容。

3. 使用数据（分析与优化）

为了提升产品稳定性与使用体验，我们可能收集以下信息：

  • 功能使用情况
  • 崩溃日志
  • 性能数据（如处理耗时）
  • 设备信息（设备型号、系统版本）

这些数据：

  • 不包含可识别个人身份的信息
  • 不与用户身份关联
  • 不用于跨应用追踪

4. 用户反馈信息

当您通过邮件等方式联系我们时，我们可能会处理您主动提供的信息，例如：

  • 电子邮箱地址
  • 问题描述或反馈内容

这些信息仅用于用户支持与问题排查。

5. 广告与设备标识符（如适用）

如果应用启用广告或归因服务，可能会使用设备标识符（如IDFA）用于：

  • 广告效果分析
  • 用户获取统计

您可以在系统设置中关闭相关权限：

设置 → 隐私 → 跟踪

二、信息的使用方式

我们仅将信息用于以下用途：

  • 提供图像编辑与色彩处理功能
  • 优化产品性能与稳定性
  • 改进用户体验
  • 响应用户反馈

我们不会将信息用于未经授权的用途。

三、信息共享

我们不会出售或出租您的个人信息。

仅在以下情况下可能共享信息：

  • 获得您的明确同意
  • 法律法规要求
  • 为保护用户或公众安全
  • 为维护合法权益

四、数据存储与安全

  • 图像数据默认仅存储在您的设备中
  • 我们采取合理措施防止数据丢失或未经授权访问
  • 数据仅在实现目的所需的最短期限内保留

五、您的权利

您可以：

  • 管理或撤回照片访问权限
  • 删除应用以清除本地数据
  • 联系我们获取支持

六、第三方服务

本应用可能使用第三方服务（如分析工具）。这些服务仅处理必要的匿名数据，并遵循其各自的隐私政策。

七、未成年人保护

若您为未成年人，请在监护人指导下使用本应用。

八、政策更新

本隐私政策可能会不定期更新。如有重大变更，我们将通过应用内提示等方式通知您。
