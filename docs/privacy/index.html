VibeColor 隐私政策

版本 1.2.5 更新 2026年9月26日

VibeColor 仅处理提供功能与改进产品所需的信息，不出售或出租您的个人信息。

1. 照片与本地处理

照片、视频及图像分析在设备本地处理，不上传您的媒体、编辑文字或项目文件。我们在需要访问或保存照片时请求授权，您可在系统设置中调整权限。作品和下载的内容保存在设备上，供编辑或离线使用。

2. 在线服务

查询更新、公告和获取模板、素材时，应用会向 VibeColor 服务（vibecolor.cn）发送必要的版本、语言、兼容信息及所请求的内容标识。服务会短暂处理 IP 地址以建立连接和防止滥用，不建立个人下载历史。

3. 匿名使用统计

为改进产品，我们可能统计模板、素材、一图成章风格、智能仿色和视频转 Live 的使用及成功保存次数。统计按日汇总，不包含个人身份、照片、视频或编辑内容，不与购买信息关联，也不用于广告、用户画像或跨应用跟踪。我们不使用第三方统计 SDK。

4. 购买与权益

购买和恢复购买由 Apple 处理。获取受限内容时，VibeColor 会向 Apple 核验签名交易证明，处理交易编号、商品及购买、到期、续订或撤销状态，仅用于确认权益和防止未经授权访问。我们不接收 Apple 账户密码或支付卡信息。

原交易证明及编号不写入我们的数据库或业务日志；验证摘要和结果仅在有界内存中短期缓存，过期后不再使用并清理。Apple 按其规则管理购买记录；删除应用不会取消订阅或删除 Apple 的记录。

5. 服务商、支持与安全

在线服务使用阿里云基础设施，服务商仅在提供网络、计算和内容传输所需范围内处理连接信息。Apple 和您主动使用的邮件等服务适用各自的隐私规则。除提供上述服务、您明确同意或法律及合法权益保护所需外，我们不共享个人信息。

联系支持时，您提供的邮箱和反馈仅用于答复与排查，保留至实现目的所需的期限。我们采取合理的安全保护措施；除上述匿名汇总外，信息仅保留必要的时间。

6. 您的选择与联系

您可管理照片权限、删除应用以清除本地数据，或联系 vibecolor@163.com 获取支持、提出隐私请求。未成年人请在监护人指导下使用。

政策更新会在应用或相关页面公布；重大变更会另行提示。若处理范围或用途变化，我们会按适用要求告知、征求同意并提供相应选择。

本页面与 VibeColor 应用内支持与法律文档保持同源更新。
