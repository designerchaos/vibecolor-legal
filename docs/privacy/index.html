VibeColor 隐私政策

版本 1.1.0 更新 2026年9月4日

VibeColor（以下简称“本应用”或“我们”）非常重视您的隐私与个人信息安全。本应用在设计上遵循最小数据收集原则，仅在必要范围内处理信息，并尽可能在您的设备本地完成所有数据处理。

请您在使用本应用前仔细阅读本隐私政策，以了解我们如何处理您的信息。

一、我们收集的信息

1. 照片访问权限

为了实现图片导入与编辑功能，VibeColor需要访问您的照片库。

  • 我们会在使用前请求您的授权
  • 您可以随时在系统设置中关闭权限

重要说明：

您选择的照片仅用于本地处理，我们不会主动收集或上传您的照片。

2. 本地数据处理

VibeColor的核心图像处理功能（包括色彩映射、风格转换等）完全在设备本地执行：

  • 不会上传图片至服务器
  • 不会建立用户图片数据库
  • 不会对图片内容进行远程分析

这意味着我们无法访问或存储您的照片内容。

3. 更新与公告查询

本应用会在启动及返回前台时向 vibecolor.cn 查询适用的版本更新提示和公告。本应用提交的业务参数仅包含平台、App 版本、App Build 编号和本应用当前语言；不包含照片、编辑内容、用户、设备、安装或会话标识。网络服务在建立连接和防滥用时会短暂处理来源 IP；来源 IP 不是请求正文中的统计字段，也不用于建立用户画像。

4. 匿名使用统计

“匿名使用统计”默认关闭。只有您在“设置 → 匿名使用统计”中主动开启后，本应用才会在您成功使用某个内置模板或内置素材时记录一次事件。

每条事件仅包含：

  • 随机生成的事件 UUID（只用于重试去重）
  • UTC 发生时间
  • App Build 编号
  • 对应的内置模板 ID 或内置素材 ID

我们不会在该事件中收集用户、设备、安装或会话标识，不会收集 IDFA，也不会收集照片、编辑内容、输入文字、相册名、文件名、精确位置、设备型号、语言或系统版本。模板内部自带的素材不会重复统计。本功能不使用第三方统计 SDK，数据仅在联网时发送至 VibeColor 自有服务器，用于汇总内置模板和素材的受欢迎程度，不用于计费、安全判断、用户权益、广告或跨应用追踪。

未发送事件只在本设备的离线队列中暂存最多 23 小时，队列最多 500 条；过期事件会被删除。服务器上的原始事件最多保留 90 天。之后仅可保留不含用户或设备标识的汇总计数。

您可以随时在“设置 → 匿名使用统计”中关闭此功能。关闭后会立即清除尚未发送的事件并停止后续收集。由于已汇总数据从不包含用户或设备标识，因此无法关联到您，也无法按个人单独删除。

5. 用户反馈信息

当您通过邮件等方式联系我们时，我们可能会处理您主动提供的信息，例如：

  • 电子邮箱地址
  • 问题描述或反馈内容

这些信息仅用于用户支持与问题排查。

二、信息的使用方式

我们仅将信息用于以下用途：

  • 提供图像编辑与色彩处理功能
  • 提供适用的版本更新提示与公告
  • 优化产品性能与稳定性
  • 改进用户体验
  • 响应用户反馈

我们不会将信息用于未经授权的用途。

三、信息共享

我们不会出售或出租您的个人信息。

仅在以下情况下可能共享信息：

  • 获得您的明确同意
  • 法律法规要求
  • 为保护用户或公众安全
  • 为维护合法权益

四、数据存储与安全

  • 图像数据默认仅存储在您的设备中
  • 我们采取合理措施防止数据丢失或未经授权访问
  • 数据仅在实现目的所需的最短期限内保留

五、您的权利

您可以：

  • 管理或撤回照片访问权限
  • 删除应用以清除本地数据
  • 联系我们获取支持

六、第三方服务

本应用不使用第三方统计 SDK。更新与公告查询以及您主动开启后的匿名使用事件只发送至 vibecolor.cn 的 VibeColor 自有服务。设备操作系统提供的相册、购买等系统服务仍受其提供方的隐私规则约束。

七、未成年人保护

若您为未成年人，请在监护人指导下使用本应用。

八、政策更新

本隐私政策可能会不定期更新。如有重大变更，我们将通过应用内提示等方式通知您。
